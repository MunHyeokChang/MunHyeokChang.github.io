Loco-sheet: Flexible Sheet-based Locomotion Robot

Loco-sheet is a flexible sheet-based soft locomotion robot developed for the IEEE RoboSoft Locomotion Competition. The robot uses tendon-driven actuation and morphing sheet structures to traverse uneven environments, including sand, stairs, turning paths, and low-clearance spaces.

My Contributions

  • Proposed the main body hardware concept.
  • Designed and fabricated the robot hardware.
  • Implemented Arduino-based motor position control.
  • Designed and fabricated the PCB.
  • Implemented wireless control.
